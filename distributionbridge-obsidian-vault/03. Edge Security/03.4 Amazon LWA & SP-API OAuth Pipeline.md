# 03.4 Amazon LWA & SP-API OAuth Pipeline

The **Amazon Selling Partner API (SP-API)** integration enables seamless connection with seller central accounts.

## OAuth Flow
1. User initiates connection with signed HMAC-SHA256 `state` parameter.
2. Amazon redirects to `/api/auth/amazon/callback` (see [[amazon-callback.js]]).
3. Worker exchanges authorization code for LWA Access & Refresh Tokens.
4. Tokens are encrypted via `AES-256-GCM` using `TOKEN_ENCRYPTION_KEY` and persisted to PostgreSQL.
