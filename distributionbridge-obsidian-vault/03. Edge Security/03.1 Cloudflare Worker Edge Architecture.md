# 03.1 Cloudflare Worker Edge Architecture

The backend operates as a distributed Cloudflare Worker edge service deployed across 300+ edge locations globally.

## Routing Engine Architecture
- `GET /health`: Diagnostic discovery and route health probes.
- `POST /api/auth/login`: PBKDF2 authentication and token generation.
- `POST /api/auth/logout`: Cookie clearance and session invalidation.
- `GET /api/auth/amazon/callback`: LWA OAuth code exchange and AES-256 token storage.
- `POST /api/sourcing/triage`: Algorithmic margin scoring and deal rank calculation.
