# 03.3 Row-Level Security Schema

PostgreSQL Row-Level Security (RLS) ensures absolute data sandboxing between wholesale partners and institutional investors.

## Security Policies & Indexes
- **Tenant Context Session Variable**:
  ```sql
  SET LOCAL app.current_investor_id = 'inv_01';
  ```
- **RLS Policy on Allocations Table**:
  ```sql
  CREATE POLICY investor_isolation_policy ON allocations
    FOR ALL
    USING (investor_id = current_setting('app.current_investor_id', true));
  ```
