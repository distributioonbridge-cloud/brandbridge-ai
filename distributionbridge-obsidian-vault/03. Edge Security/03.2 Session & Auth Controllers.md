# 03.2 Session & Auth Controllers

The session and authentication controllers enforce cryptographic verification, secure cookie serialization, and OAuth token exchanges.

## Linked Edge Modules
- **Authentication Engine**: [[auth.js]] — Handles PBKDF2 password hashing (100,000 iterations) and cryptographically signed session tokens.
- **Login Controller**: [[login.js]] — Verifies credentials and sets `HttpOnly`, `SameSite=None`, `Secure` session cookies.
- **Amazon OAuth Callback**: [[amazon-callback.js]] — Validates HMAC-SHA256 OAuth states and exchanges auth codes with Amazon LWA.
- **Logout Controller**: [[logout.js]] — Invalidates session tokens and purges client cookies.
