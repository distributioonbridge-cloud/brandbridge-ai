# 04.3 GitHub Actions & Edge Deployment Pipeline

The CI/CD pipeline automates testing, Vite bundling, static page generation, and simultaneous deployment to Cloudflare Worker Assets and Cloudflare Pages.

## Pipeline Architecture
- **Continuous Integration**: Triggers on push to `main` branch.
- **Auditing**: Runs [[audit_pipeline.py]] and Playwright verification.
- **Edge Deployment**: Deploys Worker triggers and static assets via Wrangler.
