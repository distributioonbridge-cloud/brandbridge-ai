# 04.2 Multi-Viewport Visual Regression & Golden Snapshots

The visual audit suite verifies responsive layout integrity, CSS grid wrapping, and golden snapshot alignment across 4 viewport profiles:
- **Desktop Large**: `1920 x 1080` (Widescreen Monitor)
- **Desktop Standard**: `1280 x 800` (Standard Laptop)
- **Tablet Portrait**: `768 x 1024` (iPad / Tablet)
- **Mobile Standard**: `375 x 812` (iPhone / Mobile)
