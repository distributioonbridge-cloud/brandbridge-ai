## Quick Start

```powershell
# Navigate to project
cd C:\Users\Asus\.gemini\antigravity\scratch\DistributionBridge

# Install dependencies
npm install

# Start development server
npm run dev

# Production build
npm run build

# Deploy live to Cloudflare
npx wrangler deploy -c worker-wrangler.json
```
